# Maid in Lab

## ゲーム概要

**Maid in Lab（メイド・イン・ラボ）** は、化学シミュレーション要素とファンタジー要素を融合させた錬金術ゲームです。プレイヤーは研究室で薬を調合し、自分のメイドを強化して戦わせます。

## ゲームの特徴

### 🧪 錬金術システム
- 薬草を煮出して回復薬を作成
- 温度管理や時間調整で品質が変化
- 細胞壁の破壊など、実際の化学プロセスを再現
- 序盤は現実的な化学、中盤以降でファンタジー要素が登場

### 💊 ポーション作成
- 回復薬：HPを回復
- 筋力強化薬：攻撃力アップ
- 敏捷性の秘薬：速度アップ
- 魔力増強剤：魔法攻撃強化
- その他、様々な効果のポーション

### 👗 メイド育成
- 作成した薬でメイドを強化
- ステータス管理（筋力、敏捷性、魔力など）
- 装備やスキルのカスタマイズ

### ⚔️ 戦闘システム
- 強化したメイドを戦闘に送り出す
- 戦闘報酬で新しい素材を入手
- より強力な敵に挑戦
